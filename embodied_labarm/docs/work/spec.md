## 1. 项目目标与成功标准（Goals & Success Criteria）

### 1.1 项目目标（Objectives）

面向"具身智能复杂接触操作与机构交互"赛道初赛要求，构建一套以 **VLA（Vision-Language-Action）大模型**为决策中枢，覆盖 **目标感知 → 接近对准 → 接触建立 → 受约束操作 → 结果判断** 全流程的高校智慧实验柜复杂操作方案。初赛以 **方案书 + 可交互仿真 Demo** 形式提交，满足专家评审 5 维度 × 20 分 = 100 分的评分要求，目标得分 ≥ 75 分。

## 2. 依赖与资源（Dependencies & Resources）

### 2.1 技术栈（Tech Stack）

| 层级 | 选型 | 理由 |
|---|---|---|
| **决策层（大模型）** | Qwen3-VL / InternVL2-VL（开源可离线）+ 具身动作分词器 | 高校组可学术复现，避免闭源 API 依赖 |
| **感知层** | RGB-D 单目（仿真内合成） + 六维力/力矩传感器（F/T） + 关节编码器 | 多模态融合满足「接触反馈」评分项 |
| **控制层** | 阻抗控制 + 力位混合控制 + 操作空间 admittance | 接触稳定，抗摩擦/位姿偏差 |
| **仿真环境** | 初版用 HTML5 Canvas 2D/Three.js 可交互 Demo；扩展版对应 MuJoCo/Isaac Sim | 初赛即开即用 Demo，不依赖本地安装大型仿真 |
| **运动规划** | OMPL / MoveIt2 + RRT-Connect 后置轨迹优化 | 标准成熟 |
| **世界模型（创新点）** | 轻量 Diffusion 接触状态预测模型 | 解决"机构状态不可见"难题（抽屉拉到哪了、旋钮转多少度） |

### 2.2 仿真场景（Operation Scenarios）——初赛自选

统一任务场景：**高校智能化学实验柜**，包含 4 类典型接触操作（覆盖赛题列举所有类型）：

| 编号 | 机构类型 | 任务目标 | 物理约束/难点 |
|---|---|---|---|
| O1 | **门锁（旋转锁舌）** | 识别锁孔→插入钥匙→旋转 90°→推开柜门 | 钥匙插入同轴公差 ≤ 0.5mm，旋转扭矩超限即断 |
| O2 | **抽屉（直线导轨+摩擦）** | 抓握把手→拉至最大行程→推回 | 摩擦力随负载变化（±40%），导轨间隙导致姿态漂移 |
| O3 | **旋钮/阀门（旋转限位）** | 捏住旋钮→从 0° 旋转到 270°（三档阀门） | 有档位卡滞+限位块硬接触，扭矩阈值自适应 |
| O4 | **插拔装配（试管架）** | 抓取试管→插入 24 孔试管架指定孔位→拔出 | 孔位间距 18mm，插入深度 25mm，同轴偏差自适应 |

### 2.3 鲁棒性测试矩阵（Robustness Ablation）

初赛方案中必须给出以下干扰条件的仿真实验设计（每类至少 2 个水平）：

- 目标位置偏差：±5mm / ±10mm
- 摩擦系数变化：×0.6 / ×1.4
- 机构参数变化（抽屉行程 -15% / 旋钮档位刚度 +30%）
- 操作扰动：末端 3N 侧向外力
