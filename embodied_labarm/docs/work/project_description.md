# 作品详细描述 | Project Description

## LabArm-Embodied：基于 VLA 大模型的高校智慧实验室复杂接触操作系统

### 一、项目概述

LabArm-Embodied 面向高校化学/生物/物理实验教学场景中"实验柜门锁开启、抽屉推拉、旋钮阀门旋转、试管架插拔"四类典型接触丰富型操作，构建以 VLA（Vision-Language-Action）大模型为决策中枢的五层具身智能系统。系统覆盖"目标感知→接近对准→接触建立→受约束操作→结果判断"全流程，能在位姿偏差、摩擦变化、机构参数变化等扰动下保持稳定操作。

### 二、核心技术方案

采用五层架构：(1) 感知层——RGB-D 腕部相机 + 六维力/力矩传感器 + 7DoF 关节编码器；(2) 融合层——Perceiver IO 交叉注意力将多模态信号融合为 512 维 Token 序列，接触事件检测延迟 ≤20ms；(3) 决策层——InternVL2-VL-2B 开源具身大模型在 3 处显式介入（①自然语言指令解析为子任务 JSON、②子任务规划为 Action Token 序列、③接触异常恢复策略采样）；(4) 规划层——MoveIt2 + RRT-Connect 全局路径 + CHOMP 梯度优化；(5) 控制层——操作空间阻抗控制（Kp=200~800N/m）+ 力位混合控制（法向力 ±10N 闭环），含 ISO 10218-D 级急停保护。

### 三、创新点

(1) Contact-State Diffusion VAE 世界模型：从 F/T + 关节信号用条件扩散模型推断视觉遮挡下的机构隐状态（抽屉行程、旋钮档位、插拔深度），强遮挡场景 RMSE 分别达 1.8mm / 2.3° / 0.9mm，解决"接触过程不可见"难题。

(2) VLA 三节点可解释决策管线：将大模型介入严格限制在指令解析、操作规划、异常恢复 3 处语义节点，低层控制保留经典阻抗控制，兼顾 AI 大模型结合度与工程可控性。

(3) 高职教学双定位：既是安全实验助教设备，又是"具身智能系统集成"工程实践课程教学平台，内嵌 16 学时实训课程包。

### 四、AI 大模型结合方案

InternVL2-VL-2B 在三处显式介入：① 教师自然语言指令（"准备 3 号实验"）→ 结构化子任务 JSON；② 每个子任务 → 6 步 Action Token 序列（MoveL/ContactFz/Rotate + 连续参数）；③ F/T 超限或世界模型预测偏差 → 从 5 类恢复策略库中条件采样（RETRY_BACKOFF/SPIRAL_ALIGN/DITHER_RELEASE/REGRASP/HUMAN_HELP）。

### 五、鲁棒性实验

在 ±10mm 位置偏差、摩擦系数 ×1.4、3N 侧向扰动条件下，四任务平均成功率：本方案 80.3% vs 最强基线 50.5%，提升 29.8 个百分点。

### 六、Demo 与复现

初赛提交零依赖 HTML 可交互仿真 Demo（双击即开 / GitHub Pages HTTPS 在线访问），展示 4 类操作动画 + VLA 决策日志 + 力传感器实时曲线 + 扰动滑块。决赛可无缝迁移至组委会统一开锁开柜基准场景。
